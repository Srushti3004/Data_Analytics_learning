🧮 5. Introduction to Excel Formulas

Started learning how formulas and functions are written in Excel.

Excel formulas generally begin with:

=

MAX

Returns the largest value from a selected range.

Example:

=MAX(A1:A10)
MIN

Returns the smallest value from a selected range.

Example:

=MIN(A1:A10)
AVERAGE

Calculates the average of values in a selected range.

Example:

=AVERAGE(A1:A10)
🔀 6. IF Statement

Started learning the IF function for applying logical conditions to data.

Syntax
=IF(condition, value_if_true, value_if_false)
Example
=IF(A2>=50,"Pass","Fail")

This checks whether the value in A2 is greater than or equal to 50.

If the condition is TRUE → Pass
If the condition is FALSE → Fail

The IF function is useful for making decisions based on conditions in a dataset.
